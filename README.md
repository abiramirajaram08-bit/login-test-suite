# Login Form Test Suite

A manual testing project covering the login functionality of [saucedemo.com](https://www.saucedemo.com), built as part of my software testing learning journey.

## What This Project Covers
- Test planning
- Test case design using Equivalence Partitioning and Boundary Value Analysis
- Manual test execution
- Bug/defect reporting

## Tools Used
- Manual black-box testing
- Excel (test case management)
- Markdown (documentation)

## Files in This Repo
- `test-plan.md` — scope, approach, and objective of testing
- `test-cases.xlsx` — 18 test cases covering valid/invalid login, boundary cases, and basic security checks (SQL injection, XSS attempts)
- `bug-reports.md` — defects found during execution
- `README.md` — this file
